# 01: 准确区分字幕为空、无法验证、归属冲突与接口失败

**What to build:** 本地与云端公开提取结果准确表达字幕失败原因，不把证据不足宣称为串轨，也不把归属失败转换为无字幕或 ASR 成功。来源为父 issue《BV1aDn968E2A 无前缀 AI 字幕被归属校验误拒》及规范《无归属前缀 AI 字幕兼容与归属验证规范》。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 旧接口不透明资源报告无法验证，支持的身份资源明确冲突时报告归属冲突；两端 reason 与 message 一致。
- [ ] 空列表、语言不匹配、正文空、网络、登录、限流及解析失败的结果保持可辨识。
- [ ] 拒绝资源无正文下载、导出或音频转写；本地异常编排不吞掉归属失败。
- [ ] 公开本地提取与 Worker HTTP 入口完成 T03、T04、T11、T16 的离线验证；真实客户端只 mock 外部 HTTP，不 mock 发现与归属判断。
- [ ] 单场景先红后绿，既有成功路径不回归；测试仅使用独立临时数据与合成凭证，不访问 B 站。
